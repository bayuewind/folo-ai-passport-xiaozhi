# AI Passport 使用说明书（护眼版）

适用固件：`feat/passport-eye-care` 分支，基于小智 2.5.0。
硬件：FoloToy AI Passport（ESP32-C3、8 MB Flash、ES8311 音频、240x320 屏幕、CW2017 电量计）。

## 1. 按键

设备有三个按键：上键、下键、OK 键（对话键）。

| 按键 | 操作 | 效果 |
| --- | --- | --- |
| OK 键 | 单击（待机时） | 开始对话：连接服务器并进入聆听 |
| OK 键 | 单击（聆听时） | 结束本次对话，关闭语音通道 |
| OK 键 | 单击（说话时） | 打断设备说话 |
| OK 键 | 单击（开机启动阶段） | 进入配网模式 |
| OK 键 | 单击（配网模式） | 开始或停止麦克风和喇叭测试 |
| 上键 | 单击 | 音量加 10 |
| 上键 | 长按 | 音量调到最大（100） |
| 下键 | 单击 | 音量减 10 |
| 下键 | 长按 | 静音（音量 0） |
| 任意键 | 深度休眠时按下 | 唤醒设备 |

说明：

- 音量范围 0 到 100。80% 以下与原版相同，90% 和 100% 有额外增益；出现破音请调低。
- 本机没有唤醒词，只能按 OK 键开始对话。

## 2. 屏幕

护眼版默认熄屏，只在需要时亮起。

| 情况 | 屏幕 |
| --- | --- |
| 待机、聆听、说话 | 熄灭 |
| 按上键或下键 | 亮 10 秒后熄灭，同时显示音量 |
| 按 OK 键 | 不亮屏 |
| 开机、配网、激活、升级、严重错误 | 常亮 |

- 聆听和说话时，底部不显示你说的话和设备的回复。报错等系统提示仍然显示。
- 亮屏时显示一张风景图，顶部是时间、电量和 Wi-Fi 状态。

## 3. 开始使用

### 3.1 首次联网（配网）

1. 给设备充电或接通电源，开机后在启动阶段（屏幕显示初始化）按 OK 键。
   如果设备没有保存任何 Wi-Fi，会自动进入配网模式。
2. 屏幕显示"配网模式"和热点名称，名称类似 `Xiaozhi-95B1`。
3. 手机或电脑连接这个热点。
4. 浏览器打开 `http://192.168.4.1`。
5. 选择你的 Wi-Fi，输入密码，保存。设备会重启并联网。

设备最多记住 10 个 Wi-Fi。保存第 11 个时，列表末尾最早的一个会被删除。
开机时设备连接当前能搜到的已保存 Wi-Fi。

### 3.2 服务器地址

固件默认服务器：

```text
OTA:  https://47-93-228-85.sslip.io/xiaozhi/ota/
语音: wss://47-93-228-85.sslip.io/xiaozhi/v1/
```

OTA 会下发语音地址和认证令牌。要换成自己的服务器，在配网页面的高级设置里保存 OTA 地址并重启。
设备里已保存的 OTA 地址优先于固件默认值。

### 3.3 开始对话

1. 待机时按 OK 键。
2. 听到提示音后开始说话。设备会自动判断你说完。
3. 设备回答时，再按 OK 键可以打断。
4. 想结束，在聆听时按 OK 键。

## 4. 休眠

- 待机且没有语音会话时，空闲 15 分钟后设备进入深度休眠，几乎不耗电。
- 按任意键唤醒。唤醒相当于重新开机，约 10 秒后可以对话。
- 说话、聆听、按键操作会重新计时。
- 唤醒时按的那一下不会触发配网。
- 休眠时 USB 串口会消失，这是正常现象。

## 5. 电量

- 屏幕右上角显示电量。亮屏时可以看到。
- 电量低时屏幕会弹出"电量低，请充电"。屏幕熄灭时弹窗也不可见。
- 设备没有充电检测，充电时电量图标不会显示充电状态。

## 6. 恢复和排查

| 现象 | 处理 |
| --- | --- |
| 按键没有反应 | 设备可能在深度休眠，先按一次唤醒，等约 10 秒 |
| 按 OK 键不亮屏 | 正常，护眼版只有上下键亮屏 |
| 连不上 Wi-Fi | 重新配网：开机阶段按 OK 键，换一个 Wi-Fi |
| 连上 Wi-Fi 但无法对话 | 检查服务器是否在线；屏幕不亮时可按上键查看提示 |
| 想恢复字幕 | 在 `config.json` 删除 `CONFIG_HIDE_VOICE_SUBTITLE=y` 后重新编译 |
| 想恢复常亮屏 | 删除 `CONFIG_SCREEN_OFF_UNLESS_VOLUME_KEY=y` 后重新编译 |
| 想关闭深度休眠 | 把 `CONFIG_DEEP_SLEEP_IDLE_MINUTES` 改为 0 后重新编译 |

## 7. 更换屏幕图片

屏幕图片在 `main/boards/folotoy/ai-passport/avatar/avatar.png`。更换步骤：

```sh
python3 scripts/make_avatar_bin.py 新图片.png main/boards/folotoy/ai-passport/emoji/avatar.bin --width 240
python3 scripts/build.py folotoy/ai-passport --name ai-passport --language zh-CN
```

图片宽度不要超过屏幕宽度 240 像素。设备没有 PSRAM，所以图片转成原生格式直接从 Flash 读取。

## 9. 参数一览

| 项目 | 数值 |
| --- | --- |
| 亮屏时长（按音量键） | 10 秒 |
| 深度休眠空闲时间 | 15 分钟 |
| 保存的 Wi-Fi 数量 | 最多 10 个 |
| 音量步进 | 10 |
| 屏幕 | 240 x 320 |
| 配网热点地址 | 192.168.4.1 |

## 10. 本说明未覆盖或未验证的内容

- 三个按键在设备外壳上的具体位置，请对照实物自行标注。
- 15 分钟休眠只实测过 1 分钟的测试版，15 分钟版本的数值逻辑相同。
- 电池续航、休眠电流和实际喇叭音量没有测量。
- 屏幕显示效果以实物为准。
